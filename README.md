# Terser-online

A minimalist online tool for JavaScript minification and compression.

## Live Demo

Access the live version here: [https://ravegoth.github.io/terser-online/](https://ravegoth.github.io/terser-online/)

## How it Works

This tool leverages **Terser** for advanced JavaScript minification and offers additional compression options using **Regpack** and **Zopfli**.

## Usage

1.  **Input your JavaScript code** into the provided editor.
2.  The code is automatically **minified by Terser**.
3.  Optionally, select **Regpack** or **Zopfli** for further compression.
4.  View the compressed output and copy it to your clipboard.
